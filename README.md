# Projeto Condomínio

Sistema completo para gerenciamento de condomínios utilizando:
- HTML
- CSS
- JavaScript
- Node.js
- Express
- MySQL

## Funcionalidades

- Cadastro de condôminos
- Sistema de garagem
- Chat entre moradores
- Controle de utensílios
- Reserva de salão
- Banco de dados MySQL

## Como executar

### Instalar dependências

```bash
cd backend
npm install
```

### Executar servidor

```bash
node server.js
```

### Executar banco

Importe o arquivo:
- banco.sql

### Abrir frontend

Abra:
- frontend/index.html
